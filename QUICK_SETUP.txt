SSW2 CONSTRUCTION STUDY — QUICK GITHUB PAGES SETUP

1. Extract this ZIP.
2. Create a GitHub repository, e.g. ssw2-construction-study.
3. Upload ALL extracted files/folders to the repository root.
4. GitHub repository → Settings → Pages.
5. Source = Deploy from a branch.
6. Branch = main, Folder = /(root), then Save.
7. Open the published github.io address in Safari on the iPad.
8. Safari Share → Add to Home Screen.

IMPORTANT:
Open the published HTTPS site, not index.html from the iPad Files app.
